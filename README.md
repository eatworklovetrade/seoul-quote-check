# Seoul Quote Check

Check a Korean skin-clinic price quote (screenshot or text) against what Koreans pay and prices abroad. Runs entirely in the browser: text recognition uses [tesseract.js](https://github.com/naptha/tesseract.js) (Apache-2.0) with language data from tessdata. No sign-in; images never leave the device.

Price data as of 11 Nov 2026. Not medical advice; this site takes no money from clinics and does not book or recommend clinics.
